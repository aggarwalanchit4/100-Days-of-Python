## 📂 File Modes

- `r` - Read a file
- `w` - Write to a file and overwrite existing content
- `a` - Append data to the end of a file
- `x` - Create a new file; gives an error if the file already exists
- `r+` - Read and write
- `w+` - Write and read
- `a+` - Append and read
