## 🧠 Core Concepts

### Class
A class is a blueprint used to create objects.

### Object
An object is an instance of a class and can have its own data.

### Constructor
`__init__()` is automatically called when an object is created.

### self
`self` refers to the current object and is used to access its attributes and methods.

### Methods
Methods are functions defined inside a class that can work with object data.
